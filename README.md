# Репозиторий с учебными проектами курса "Специалист по Data Science" от "Яндекс Практикума"

## Описание проектов

Данные проекты были выполнены в ходе обучения в "Яндекс Практикуме", профессии "Специалист по Data Science".

| Название проекта      | Описание                                                                                           | Используемые библиотеки     |
|:---------------------:|:-------------------------------------------------------------------------------------------------:|:---------------------------:|
| [Яндекс музыка](yandex_music/kozubova_a_yandex_music_project.ipynb) | Анализ предпочтений пользователей Яндекс.Музыки из Москвы и Санкт-Петербурга с учетом времени суток (утро и вечер) и дней недели (понедельник, среда, пятница). | pandas                      |
| [Исследование надежности заемщиков](credit_worthiness/kozubova_a_credit_worthiness_project.ipynb) | Анализ влияния различных факторов на факт погашения кредита в срок: количество детей в семье клиента, семейное положение, уровень дохода, цели кредита. | pandas                      |
| [Исследование объявлений о продаже квартир](real_estate/kozubova_a_real_estate_project.ipynb) | Выявление параметров, влияющих на цену жилых объектов. Определение рыночной стоимости объектов недвижимости. | pandas, matplotlib                      |
