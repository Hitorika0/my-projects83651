# Репозиторий с учебными проектами курса "Специалист по Data Science" (Яндекс Практикум)

В этом репозитории собраны учебные проекты, охватывающие различные прикладные области: HR-аналитику, нефтегазовый сектор, e-commerce, сельское хозяйство, рынок недвижимости и другие. Помимо анализа данных, проекты включают обучение ML-моделей для решения прикладных бизнес-задач.

## Навигация и формат ноутбуков

Все проекты в этом репозитории оформлены в формате .ipynb и .html, с чёткой структурой заголовков и интерактивным оглавлением для удобной навигации. 

**Важно**: все ноутбуки в этом репозитории созданы в Jupyter Notebook версии 7+. При просмотре таких файлов на GitHub:

- Интерактивное оглавление может работать некорректно
- Могут не отобразиться некоторые продвинутые визуализации (например: `sunburst`, интерактивные графики на Plotly)

Это связано с ограничениями рендера на стороне платформы и не затрагивает саму структуру ноутбука.

## Рекомендую:

* Скачать html-версию — она лежит рядом с ipynb-файлом и открывается в любом браузере
* Открывать ноутбуки локально через Jupyter Notebook
