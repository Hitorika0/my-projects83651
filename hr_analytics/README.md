# Описание проекта: "HR-аналитика"

Мы исследовали данные о сотрудниках компании для оптимизации управления персоналом:

* Выявили характеристики сотрудника с высоким и низким уровнем удовлетворённости.
* Составили портрет уволившегося сотрудника и сотрудника, который продолжает работу в компании.
* Обучили две прогнозные модели для предсказания: 1) уровня удовлетворённости сотрудника, 2) вероятного ухода сотрудника из компании.
* Предоставили бизнесу рекомендации для сокращения текучести и повышения уровня удовлетворённости сотрудников.

## Особенности ноутбука

Ноутбук содержит четкую структуру заголовков и оглавление для навигации, а также продвинутые интерактивные графики (например, `Plotly` или `sunburst`).
Он создан в **Jupyter Notebook версии 7.4.3**, которая использует обновлённую систему разметки и визуализации.

**Важно**: при открытии .ipynb-файлов, созданных в Jupyter 7+, через GitHub могут ** не работать кликабельные ссылки в оглавлении и не отображаться интерактивные графики** — особенно такие, как `Plotly`, `sunburst`.

Чтобы получить интерактивное оглавление и корректное отображение графиков:

* Откройте версию ноутбука в формате `.html`, которая лежит рядом с `.ipynb`-файлом.

Вы можете скачать `.html`-файл и открыть его в любом браузере.
