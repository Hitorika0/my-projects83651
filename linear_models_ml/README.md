# Описание проекта: "Линейные модели в машинном обучении"

В этом исследовании мы:

* Проанализировали данные ассоциации пастбищ «ЭкоФерма».
* Создали две прогнозные модели для отбора бурёнок в поголовье для владельца молочного хозяйства «Вольный луг».
* С помощью моделей отобрали коров по двум критериям: 1) cредний удой за год — не менее 6 000 кг, 2) молоко должно быть вкусным.

## Особенности ноутбука

Ноутбук содержит четкую структуру заголовков и оглавление для навигации. 
Он создан в **Jupyter Notebook версии 7.4.3**, которая использует обновлённую систему разметки и визуализации.

**Важно**: при открытии `.ipynb`-файлов, созданных в Jupyter 7+, через GitHub может наблюдаться некорректное отображение оглавления.
Это вызвано **техническими ограничениями платформы GitHub при отображении ноутбуков нового формата и не связано с качеством кода или наличием ошибок в проекте**.

Чтобы получить полный функционал навигации по оглавлению, пожалуйста, используйте один из следующих способов:

* Откройте версию ноутбука в формате `.html`, которая лежит рядом с `.ipynb`-файлом.

Вы можете скачать `.html`-файл и открыть его в любом браузере.

* На GitHub используйте веб-редактор github.dev:
  
Откройте `.ipynb` файл, затем в правом верхнем углу нажмите **More edit options → Open with... → github.dev**.
После открытия в левой нижней панели включите отображение **Структуры**, чтобы быстро перемещаться по разделам.

* Откройте ноутбук локально через Jupyter Notebook
