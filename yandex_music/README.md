# Описание проекта "Яндекс музыка"

Цель исследования - проверить гипотезы и сравнить поведение пользователей из Москвы и Санкт-Петербурга.

Для анализа используются данные "Яндекс Музыки" из файла `yandex_music_project.csv`, содержащие следующую информацию:

* Идентификатор пользователя;
* Название трека;
* Имя исполнителя;
* Жанр;
* Город пользователя;
* Время прослушивания;
* День недели.

## Особенности ноутбука

Ноутбук организован с использованием четкой структуры заголовков и оглавления для навигации.
Обратите внимание, что из-за технических ограничений рендера Jupyter Notebook (версия 7+) на платформе GitHub кликабельные якоря в оглавлении `.ipynb` файлов могут не работать корректно. Это ограничение GitHub и никак не связано с самим ноутбуком.

Чтобы получить полный функционал навигации по оглавлению, пожалуйста, используйте один из следующих способов:

* В проекте представлена версия ноутбука в формате `.html`. Вы можете скачать этот файл и открыть его в любом браузере.

* На GitHub используйте веб-редактор github.dev:
  
Откройте `.ipynb` файл, затем в правом верхнем углу нажмите **More edit options → Open with... → github.dev***.
После открытия в левой нижней панели включите отображение **Структуры**, чтобы быстро перемещаться по разделам.

* Открывайте ноутбук локально через Jupyter Notebook
